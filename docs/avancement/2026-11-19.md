# 2026-11-19

## Release 0.1.0 : plantage du scan sur Android
- Essai de l'APK `Rohy-android-0.1.0-test-signature.apk` sur le Galaxy S24 Ultra : l'app plante dès qu'on
  touche « Scanner le QR code » (`NullPointerException` dans le scanner ML Kit).
- Cause : la release est minifiée par R8 (mode complet). La règle fournie par ML Kit garde les classes
  `*Registrar` mais pas leur constructeur sans argument ; Firebase Components les crée par réflexion, donc
  ML Kit démarre sans ses composants. Le build debug (non minifié) n'a pas le problème.
- Correctif : règle `-keep … ComponentRegistrar { <init>(); }` dans `android/app/proguard-rules.pro`.
- Garde-fou : `scripts/check-r8-registrars.sh` lit le rapport R8 (`usage.txt`) et échoue si un constructeur
  de registrar a été retiré. Lancé par `scripts/check-android.sh` (CI et pre-push), qui construit maintenant
  aussi la release, et par l'action « Releases ».
- Vérifié sur le Samsung : APK de release corrigé installé, le scanner s'ouvre et analyse l'image.
- À faire : publier une 0.1.1 (la 0.1.0 brouillon a le bug).
