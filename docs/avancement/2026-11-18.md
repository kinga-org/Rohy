## Test réel (Galaxy S24 Ultra, Android 17, One UI 9 ; MacBook Pro, macOS 27)
- Premier essai : connexion impossible. Cause : Android bloque le trafic `ws://` non chiffré par défaut.
  Corrigé par une configuration réseau dédiée (les données restent chiffrées par l'app).
- Après correction : association, Mac → Android et Android → Mac fonctionnent ; Bonjour trouve le Mac.
- Ajout de « Envoyer au Mac » dans le menu de sélection de texte (sous ⋮).

## Problèmes rencontrés
- CI en `startup_failure` sur le compte personnel (probablement facturation) : résolu par le transfert dans l'org.
- Compose et OkHttp récents exigent l'API Android 37 (absente du SDK local) : versions compatibles API 36 épinglées.
